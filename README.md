# Nexora 0.2

Nexora is a student opportunity discovery platform designed to help students
find scholarships, competitions, hackathons, research opportunities,
internships, and Olympiads.

## Features

- Scholarships
- Competitions
- Hackathons
- Research opportunities
- Internships
- Olympiads
- Search and filtering
- Opportunity details
- Save/bookmark opportunities
- Student profiles
- User authentication

## Technology

- Python
- Flask
- HTML
- CSS
- JavaScript
- GitHub
- Render

## Goal

Nexora aims to make high-quality educational and career opportunities
easier for students to discover and access, especially students who have
limited access to guidance and resources.
